# 5 букв — Wordle на Go

Консольная игра на Go, вдохновлённая **Wordle**. Нужно угадать загаданное русское слово из пяти букв за **6 попыток**. После каждого хода игра показывает, какие буквы стоят на своих местах, какие присутствуют в слове, но находятся не на своих позициях, а каких букв в ответе нет.

Проект разработан в рамках **Т-Академии**. В нём я практиковал проектирование небольшого Go-приложения, разделение ответственности между пакетами, обработку пользовательского ввода и автоматическое тестирование.

## Возможности

- **Русские слова из пяти букв** и проверка корректности ввода.
- **Два уровня сложности** и **три категории слов**: животные, города и еда.
- **Подсказки после каждой попытки**: правильная позиция, буква не на месте или отсутствие буквы.
- **История попыток** и отображение количества оставшихся ходов.
- **Статистика за текущий запуск**: победы, поражения и общее число игр.
- **Несколько партий подряд** без перезапуска приложения.
- **Детерминированный выбор слова** с помощью флага `--seed` для воспроизведения сценариев.
- **Автоматические тесты** игровой логики и консольного интерфейса.

## Как играть

После запуска выберите новую игру в меню, затем категорию слов и уровень сложности. Вводите по одному слову из пяти русских букв.

Обозначения:

| Символ | Значение |
| --- | --- |
| ✅ | Буква стоит на правильной позиции |
| 🟡 | Буква есть в слове, но стоит не на своей позиции |
| ❌ | Буквы нет в загаданном слове с учётом повторений |

Пример формата результата:

```text
❌🟡❌❌🟡 арбуз
Осталось попыток: 5
```

Если слово угадано, игра сообщает о победе и количестве использованных попыток. После шестой неудачной попытки показывает загаданное слово.

## Требования

- **Go 1.26+** (проект проверялся с Go 1.26.6).
- Терминал с поддержкой UTF-8 для отображения русских букв и символов подсказок.

## Запуск

Клонируйте репозиторий и перейдите в каталог проекта:

```bash
git clone https://github.com/artem93plf/go-wordle-cli.git
cd go-wordle-cli
```

Запуск:

```bash
go run ./cmd/fiveletters
```

Запуск с фиксированным seed:

```bash
go run ./cmd/fiveletters --seed 42
```

`--seed` позволяет воспроизводить выбор загаданного слова при одинаковых настройках игры. Это удобно для отладки и тестирования.

## Структура проекта

```text
cmd/fiveletters/  — точка входа, разбор флага --seed
cli/              — меню, ввод и вывод, управление игровыми сессиями
game/            — правила игры, проверка слов, словари и подсказки
```

**Разделение ответственности:** пакет `game` содержит игровую логику и не зависит от консольного ввода/вывода; пакет `cli` отвечает за взаимодействие с пользователем; `main` связывает их и запускает приложение.

## Тестирование и качество кода

Проект использует стандартный пакет Go `testing`, в том числе **табличные тесты** (`table-driven tests`). Проверяются игровая логика, корректность подсказок, обработка неверного ввода, победа и поражение, повторный запуск партии и работа статистики.

Запуск тестов:

```bash
make test
```

Проверка форматирования и линтеров:

```bash
make check
```

Проверка с детектором гонок:

```bash
make test-race
```
