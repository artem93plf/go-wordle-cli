# Домашнее задание №1: «5 букв»

Описание задачи: [TASK.md](TASK.md)

## Текущее состояние - MR3

Реализован пакет game:
- встроенный словарь из 50 уникальных пятибуквенных русских слов;
- проверка входного словаря: непустой набор любого размера, отсутствие повторов, длина слов и допустимые русские буквы, включая ё;
модель GameSession с ответом, словарём, лимитом попыток, использованными попытками, историей и статусом;
- StartGame(dictionary, maxAttempts, seed) для создания сессии;
- воспроизводимый выбор ответа локальным генератором по seed;
- копирование входного словаря для независимости сессии от последующих изменений исходного слайса.
- Новая сессия имеет статус StatusGameInProgress, пустую историю и ноль использованных попыток.
Реализована обработка попыток:
- функция ApplyGuess для применения попытки к игровой сессии;
- проверка слова на длину, русские буквы и наличие в словаре;
- регистронезависимый ввод;
- результат проверки каждой буквы: ✅, 🟡 или ❌;
- корректная обработка повторяющихся букв;
- увеличение числа использованных попыток и сохранение истории;
- переход в StatusGameWin при правильном ответе;
- переход в StatusGameLose после исчерпания попыток;
- запрет новых попыток после завершения игры;
- невалидная попытка не изменяет состояние игровой сессии.
- добавлено меню: новая игра, выход.
- Возможность сыграть несколько игр без перезапуска программы.
-Устойчивость к некорректным пунктам меню и пользовательскому вводу.
- Отображение истории и количества оставшихся попыток.
- Проверка на правильность ввода и отображение сообщения об ошибке.
- добавлены уровни сложности с разными словарями
- добавлены категории слов
- добавлена статистика игрока за один запуск
- добавлен цветной вывод при поражении
- добавлен цветной вывод при победе
