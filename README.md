# Домашнее задание №1: «5 букв»

Описание задачи: [TASK.md](TASK.md)

## Текущее состояние - MR1

Реализован пакет game:
- встроенный словарь из 50 уникальных пятибуквенных русских слов;
- проверка входного словаря: непустой набор любого размера, отсутствие повторов, длина слов и допустимые русские буквы, включая ё;
модель GameSession с ответом, словарём, лимитом попыток, использованными попытками, историей и статусом;
- StartGame(dictionary, maxAttempts, seed) для создания сессии;
- воспроизводимый выбор ответа локальным генератором по seed;
- копирование входного словаря для независимости сессии от последующих изменений исходного слайса.
- Новая сессия имеет статус StatusGameInProgress, пустую историю и ноль использованных попыток.
